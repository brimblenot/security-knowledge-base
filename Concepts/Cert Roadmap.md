# Certification Roadmap

A deliberate certification path toward **security engineering and cloud security engineering** roles. The strategy is simple: build depth across the three pillars those roles draw on — security, cloud, and networking — and pair every certification with a hands-on lab or project so the credential is backed by demonstrable work.

## Current status

| Certification | Focus | Status |
|---------------|-------|--------|
| CompTIA Security+ (SY0-701) | Security foundation (DoD 8570 IAT II) | ✅ Certified |
| AWS Certified Solutions Architect – Associate (SAA-C03) | Cloud architecture | 🔄 In progress |
| Cisco CCNA | Networking foundation | 🔄 In progress |

## Planned sequence

1. **CompTIA Security+ (SY0-701)** — the security baseline; also satisfies DoD 8570 IAT Level II for cleared roles. *(Complete.)*
2. **AWS Certified Solutions Architect – Associate (SAA-C03)** — the anchor cloud certification: broad coverage of compute, networking, storage, IAM, and architecture, and widely recognized by recruiters as the standard associate-level cloud credential.
3. **Cisco CCNA** — a strong networking foundation (routing, switching, subnetting, network security). It grounds the fundamentals that both cloud and security work rely on, and carries added weight in the cleared and network-adjacent job market.
4. **HashiCorp Terraform Associate** — Infrastructure-as-Code, the skill that defines modern cloud and security engineering. Fast to earn and high-value alongside hands-on AWS work.
5. **AWS Certified Security – Specialty** — the differentiator that fuses cloud and security into a cloud-security-engineer profile, taken after the grounding provided by SAA.
6. **CISSP** — a longer-term goal for architecture and management credibility; requires roughly five years of experience (can be passed early and held as Associate of ISC2 until the experience requirement is met).

## Approach: every certification is paired with an artifact

Certifications open doors; hands-on projects demonstrate the ability to do the work. Each credential is backed by applied evidence:

- **AWS SAA** → deploy a real application on AWS and document the architecture.
- **AWS Security Specialty** → secure that deployment with least-privilege IAM, CloudTrail, and GuardDuty, documented like the [SOC lab](../Labs/_index.md).
- **Terraform** → provision the above as Infrastructure-as-Code with security controls built in.

## Notes

- **Cloud vendor:** AWS is the primary focus as the market leader. Azure would be considered for Microsoft-centric or specific government environments (some DoD work favors Azure Gov / AWS GovCloud).
- **AWS Cloud Practitioner** is intentionally not pursued as a separate exam — it is a foundational credential aimed at those with no cloud exposure, and the Solutions Architect – Associate fully supersedes it for this background. The foundational material is covered as study preparation without sitting the exam.
- Exam version codes update periodically; current codes are verified on aws.amazon.com/certification before booking.
